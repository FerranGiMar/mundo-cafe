Qué puedes pedir

En esta aplicación puedes consultar la carta de la cafetería, elegir productos y hacer pedidos de forma sencilla. La idea es reunir en una misma web las opciones principales del negocio.

Café de especialidad

Selección de cafés pensada para quienes buscan sabores más intensos y variedades diferentes dentro de la carta.

Clásicos imprescindibles

Opciones habituales para el día a día, con sabores reconocibles y preparaciones clásicas.

Tés e infusiones

Alternativas al café para ampliar la oferta de la web con bebidas calientes y opciones sin cafeína.

SERVICIOS DISPONIBLES

Envío

Recogida en tienda

Reserva tu próximo café

La aplicación permite realizar pedidos para envío a domicilio, recogida en tienda o entrega programada según la necesidad del usuario.

SOBRE LA CARTA

La carta combina cafés, tés, infusiones, repostería y lotes. El objetivo ha sido trasladar esa variedad a una web clara y fácil de usar.

OBJETIVO DEL PROYECTO

Este proyecto busca desarrollar una aplicación web para una cafetería donde el usuario pueda registrarse, hacer pedidos, consultar su perfil y gestionar un sistema de puntos.
