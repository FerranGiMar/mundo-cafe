# Apuntes rapidos

## Estructura minima de HTML

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Titulo</title>
  </head>
  <body>
    Contenido
  </body>
</html>
```

## Etiquetas que debes dominar primero

- `h1` a `h6`: titulos
- `p`: parrafos
- `a`: enlaces
- `img`: imagenes
- `ul` y `li`: listas
- `form`: formularios
- `input`: campos
- `button`: botones
- `header`, `main`, `section`, `footer`: estructura semantica

## Consejo

Si dudas entre varias etiquetas, piensa primero en el significado del contenido, no en como se ve.
