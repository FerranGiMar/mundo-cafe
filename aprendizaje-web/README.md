# Plan de arranque web

Este bloque es para volver a coger ritmo con HTML, CSS y JS sin agobiarte.

## Como usarlo

1. Abre esta carpeta en VS Code.
2. Haz un ejercicio cada dia entre semana.
3. Escribe el codigo tu mismo, aunque mires el ejemplo.
4. Cuando termines un ejercicio, rehazlo sin mirar durante 10 minutos.

## Orden recomendado

### Semana 1

- `01-html-estructura/ejercicio-1.html`
- `02-html-cafeteria/ejercicio-2.html`
- `03-formulario/ejercicio-3.html`

## Reglas de estudio

- Lee la teoria rapida de cada archivo.
- Completa los `TODO`.
- Abre el HTML en el navegador y revisa el resultado.
- Si te atascas, vuelve aqui y lo resolvemos juntos.

## Lo que estamos entrenando

- Estructura basica de una pagina HTML
- Etiquetas de texto
- Listas
- Imagenes
- Enlaces
- Formularios
- Etiquetas semanticas

## Siguiente paso

Cuando acabes estos 3 ejercicios, seguimos con CSS basico:

- colores
- clases
- margenes
- padding
- tarjetas
