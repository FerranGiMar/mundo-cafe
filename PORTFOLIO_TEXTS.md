## Texto Para LinkedIn

He finalizado y mejorado un proyecto web full stack orientado a portfolio: una aplicacion para una cafeteria con autenticacion de usuarios, catalogo de productos, carrito, gestion de pedidos, perfil persistente y sistema de recompensas por puntos.

La aplicacion esta desarrollada con HTML, CSS, JavaScript, Node.js, Express y PostgreSQL. Ademas de implementar la funcionalidad principal, trabaje en reforzar la seguridad de contrasenas, la persistencia real de datos, la estructura del backend y la presentacion del proyecto para GitHub.

## Bullet Points Para Entrevista

- Implemente un backend propio con Express y PostgreSQL para gestionar usuarios, pedidos y recompensas.
- Sustitui contrasenas en texto plano por hashing seguro y configure sesiones de usuario.
- Conecte la interfaz con una API real para perfil, pedidos e historial.
- Refactorice el proyecto para dejarlo en un estado presentable para portfolio tecnico.
